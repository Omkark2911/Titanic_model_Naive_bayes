# Titanic_model_Naive_bayes

# 🚢 Titanic Survival Prediction

A Machine Learning project that predicts whether a passenger survived the Titanic disaster using **Naive Bayes**.

## 🛠️ Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* Google colab

## 🔄 Steps

* Data Cleaning
* Handling Missing Values
* Feature Encoding
* Train-Test Split
* Naive Bayes
* Model Prediction
* Model Evaluation

## 📊 Evaluation

The model was evaluated using:

* **Accuracy Score**
* **Classification Report** (Precision, Recall, F1-score)

## 🎯 Target

`Survived`

* `0` → Not Survived
* `1` → Survived
